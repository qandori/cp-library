# Dynamic wavelet exploration

Temporary, fixed experiment package. Baseline829efa17b452f904eef5558930d91dd3792feffa. No third-party code. Source changes are isolated patches, not changes to library headers.

The matrix has13 candidates and63 baseline/candidate comparisons per compiler target. Every comparison has six alternating AB/BA pairs. Baseline A/A calibration has four cases, six pairs each, targeting1.5 process-CPU seconds per sample. Candidate samples target0.4seconds; minimum0.15seconds is reported, never enforced by rerunning. One pilot per leg fixes a common replay count from the faster pilot. All pilots, adverse samples and partial output are retained. Six alternating pairs are three ABBA blocks, not six independent confidence intervals. Four A/A families do not calibrate the unmeasured select/neighbor/wide families. A/A variability is a resolution limit: small candidate differences inside it are inconclusive, not success/failure. Screening is not merge qualification and cannot establish fastest AtCoder performance.

Two independent jobs use exact preinstalled GCC15.2.0 on ubuntu-26.04. Native uses AtCoder-style -O2 -std=gnu++23 -fmodules -ftrivial-auto-var-init=zero -DONLINE_JUDGE -DATCODER -march=native, no NDEBUG/noLTO. Portable omits only march. CPU/ISA/compiler/source/binary hashes are recorded. CPU affinity selects first permitted CPU.

Before timings every candidate runs three freshly constructed mixed replays with full output/final-state equality checks and a separate Python std::vector-equivalent oracle. Every candidate also compiles/runs extended architecture tests; affected candidates run the aggregate-backend/select-only, internal-root edge and extended leaf regressions. Every measured variant/case/flag first passes three freshly reset replays with exact full-output and final-vector equality; cross-variant preflight arrays are byte-equal. Each timed operation replay hashes all outputs outside the interval and checks against the preflight result; its first full final-state readback is checked too. Build-only output is empty: each timed build escapes the actual object, but full result readback occurs in preflight and only the first timed replay, not every timed build replay. Each benchmark replay starts from the original vector, not the previous mutated state. Input generation, construction (except explicit fresh build/capacity-reuse rebuild), warmup, destructor, digest and full-state extraction are untimed. Output stores and two constant-size opaque escape calls are timed; no result checksum is timed. Optional outputs include a separate presence bit, avoiding sentinel collisions.

Warm means1024 access-prewarm queries on a freshly built structure; it does not mean a warmed full workload replay. Boundary location, where used, is periodic BlockBits positions, not internal leaf boundaries. Narrow range anchors are uniformly generated keys with up to16-key width. This initial matrix does not use cold mode; harness cold mode perturbs512MiB before each batch, which then warms progressively.

Nominal timed CPU per job:374.4seconds, plus126 candidate pilots,8 AA pilots, preflights, compilation, untimed setup/validation, and sample-granularity overshoot. Wall completion time is not established. Per job there are1,038 benchmark processes (100 preflights,134 pilots,804 measurements) and39 compiler commands; exact-case preflight state readback, slower-leg inflation, replay rounding and host overhead add unknown cost. There is an explicit40-minute execution-step timeout and45-minute job timeout preserving time for artifact upload. Each command has a240-second bound. Native/portable jobs run independently. A timeout or failed gate preserves partial artifacts and means incomplete, never selective acceptance. Artifact retention14days, no raw results committed.

Candidate descriptions: leaf interval-only rotation; height proven compile-time path bound; neighbors fused boundary search; paired interleaved rank descent; pdep guarded BMI2 select; avxbuild guarded AVX2 packed-bit construction; reservebuild exact internal-node reserve; directbuild reserve plus contiguous-level/no-temp build; noop/noopearly rank-proven unchanged moves before/after fallback; selectprefix singleton validation with shorter reverse path; rangeprefix shared-bound count prefix; uniformneighbors fused search plus globally uniform-level skipping. Composite candidates are labeled and must be separated before attributing marginal effects.

# Wavelet Matrix のベンチマーク

リポジトリのルートで実行します。時間の単位は ms です。

```sh
g++ -std=c++23 -O2 -DNDEBUG -I . test/benchmark/wavelet_matrix.cpp -o /tmp/wavelet-matrix-bench
/tmp/wavelet-matrix-bench 200000 200000 0 64 0
```

引数は要素数、クエリ数、データの種類、整数の幅（32 / 64）、区間長の上限です。種類は 0 が `[0, 10^9)`、1 が `[0, 256)`、2 が整数型の全域、3 が種類 2 の昇順、4 が降順、5 が `[0, n/8)` の配列です。区間長の上限 0 は制限なしです。`select` だけ最大 2 万クエリを測ります。

2026-10-14 の macOS arm64、GCC 15.2 / Apple Clang 21、上記の条件で 5 回交互に実行した中央値です。変更前は `849ba87`。全ケースで結果の checksum が一致し、32bit・全域の 64bit・重複が多い配列・短い区間でも比較しています。

内部は 2 bit ごとの Wavelet Matrix です。整数の座標圧縮には radix sort、連続する整数の辞書検索には直接計算を使います。圧縮した原配列と出現位置に追加で `O(n + σ)` の整数を保持し、`access` を `O(1)`、`select` を辞書検索後 `O(1)` にしています。

和の累積配列は選択に必要な部分だけ保持します。既定の `__int128` の和は、正の値の総和と負の値の総和がそれぞれ 64bit に収まる場合に内部を 64bit にします。返り値の型は変えません。和を使わない場合は累積配列を作りません。

全要素が同じ配列は別に処理し、索引や累積配列も作りません。

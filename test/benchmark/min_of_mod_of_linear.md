# Min of Mod of Linear のベンチマーク

2026-10-15、macOS arm64 / GCC 15.2、`-std=c++23 -O2 -DNDEBUG`。各入力 300,000 問、seed 713、実装の順序を変えて 5 回計測した中央値です。単位は ms、すべての checksum が一致しています。

```sh
g++ -std=c++23 -O2 -DNDEBUG -I . test/benchmark/min_of_mod_of_linear.cpp -o /tmp/minmod-benchmark
/tmp/minmod-benchmark random 300000 5
```

引数は入力の種類、問題数、反復回数です。入力生成・入出力は計測に含めません。

| 入力 | 128 bit 除算 | 64 bit 除算併用 | 近似分数・除算で上限判定 | 近似分数・積で上限判定 | 採用実装 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `random`：10 億以下 | 122.10 | 52.35 | 65.46 | 54.25 | 48.53 |
| `short`：区間長 64 以下 | 34.03 | 18.32 | 38.87 | 20.58 | 16.00 |
| `fibonacci`：連続するフィボナッチ数 | 718.32 | 203.50 | 175.10 | 178.77 | 206.91 |
| `wide`：64 bit 全域 | 245.92 | 210.52 | 110.19 | 91.62 | 73.67 |
| `wide_short`：64 bit 全域、区間長 64 以下 | 13.21 | 10.84 | 9.61 | 9.13 | 9.32 |
| `fibonacci64`：大きなフィボナッチ数 | 677.97 | 792.56 | 385.23 | 371.59 | 319.26 |
| `period`：区間長と法が等しい | 111.22 | 43.59 | 53.49 | 53.57 | 32.14 |

`wide_euclid` は折り返し直後の候補だけを残してユークリッド互除法で縮小し、積の除算に常に 128 bit を使います。`native_euclid` は積が 64 bit に収まる場合に通常の除算を使います。`bounded_fractions` と `fractions` は [参考記事](https://maspypy.com/library-checker-min-of-mod-of-linear) の近似分数による方法を独立に実装した候補です。

採用実装は、法が 32 bit に収まる場合に 64 bit の積・除算だけで区間を縮め、それ以外では近似分数を使います。近似分数では位置の上限判定を積で行い、除算を減らしています。全周期を含む場合は最大公約数から直接求め、不要な剰余計算、動的確保、再帰を避けています。

32 bit のフィボナッチ数では近似分数の候補が速いものの、通常の範囲・短い区間では区間を縮める方式が速いため、値の範囲による切り替えを採用しました。各段階で剰余を条件付きにする案も比較し、通常の無条件の剰余計算より遅かったため採用していません。

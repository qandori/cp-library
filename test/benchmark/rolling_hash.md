# Rolling Hash の比較

2026-10-16、macOS arm64 / GCC 15.2、`-std=c++23 -O2 -DNDEBUG`。長さ 1,000,000、区間ハッシュ 1,000,000 回・LCP 100,000 回、seed 713、実行順を変えた 9 回の中央値です。累乗キャッシュは構築済みとし、入力生成は計測から除外しています。各実装の checksum は一致しています。単位は ms です。

```sh
g++ -std=c++23 -O2 -DNDEBUG -I . test/benchmark/rolling_hash.cpp -o /tmp/rolling-hash-benchmark
/tmp/rolling-hash-benchmark 1000000 1000000 9 random
/tmp/rolling-hash-benchmark 1000000 1000000 9 same
```

引数は文字列長、区間ハッシュの回数、反復数、入力の種類です。`random` は英小文字のランダム列、`same` は同じ文字の繰り返しです。LCP は先頭の最大 100,000 組の両端から始まる接尾辞同士を比較します。

実装 0 は本ライブラリ、1 は 128 bit の `%`、2 は Mersenne 素数用の剰余計算と加算を分ける版です。全実装で法・基数・入力・問い合わせを共有します。出力は実装番号・構築・区間ハッシュ・LCP・checksum です。

| 入力 | 実装 | 構築 | 区間ハッシュ | LCP |
| --- | --- | ---: | ---: | ---: |
| `random` | 128 bit `%` | 6.72 | 5.05 | 20.47 |
| `random` | 剰余計算と加算を分離 | 3.82 | 4.27 | 15.55 |
| `random` | 本ライブラリ | 2.96 | 5.18 | 16.58 |
| `same` | 128 bit `%` | 6.82 | 5.68 | 21.84 |
| `same` | 剰余計算と加算を分離 | 4.04 | 5.74 | 18.82 |
| `same` | 本ライブラリ | 2.93 | 4.68 | 18.84 |

Mersenne 素数の性質を使って 128 bit の積を折り畳み、構築時は文字の加算まで済ませてから剰余を求めます。累乗は全インスタンスで共有し、区間の左端が 0 なら累乗との乗算を省きます。構築は積と加算を分ける版より速く、区間取得・LCP は入力によって差が変わるため、すべての処理で最速とは限りません。

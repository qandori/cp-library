[mod 2 専用行列](matrix_mod2.md)の内部部品です。通常は `math/matrix_mod2.hpp` の `MatrixMod2` を使います。和を XOR、積を AND として、64 個の成分を 1 個の整数にまとめて処理します。

`matrix_mod2_detail::Word` は `std::uint64_t` です。各行を列番号の小さい方から格納し、列 `j` は行の第 `j / 64` ワードの下位から `j % 64` 番目のビットに対応します。行末の未使用ビットは 0 にします。行と行の間には、指定したワード数だけの間隔を取ります。

以下では $$W(t)=\lceil t/64\rceil$$、行数を $$n$$、掃き出しの対象となる係数の列数を $$c$$、1 行を格納するワード数を $$s$$ とします。掃き出しは、ある行に別の行を XOR して形を整える処理です。各行で基準となる最初の 1 をピボットと呼びます。

内部関数は全て `matrix_mod2_detail` 名前空間にあります。表の空間は、返り値を含む追加空間です。64 bit 整数の演算・比較・コピーを定数時間とします。

| 操作・型 | 内容・返り値 | 時間計算量 | 追加空間 |
| --- | --- | --- | --- |
| `Word` | 1 ワードの型 `std::uint64_t` | —（型） | —（型） |
| `words(n)` | `n` ビットを格納するワード数を `size_t` で返す。`n >= 0` | $$O(1)$$ | $$O(1)$$ |
| `mask(n)` | 下位 `n` ビットが 1 の `Word` を返す。`0 <= n <= 64` | $$O(1)$$ | $$O(1)$$ |
| `bit(row,column)` | 行の列 `column` の値を `bool` で返す | $$O(1)$$ | $$O(1)$$ |
| `xor_row(to,from,first,stride)` | `to[j] ^= from[j]` を `first <= j < stride` に対して行う。返り値は `void` | $$O(\mathrm{stride}-\mathrm{first})$$ | $$O(1)$$ |
| `eliminate(data,rows,stride,columns,reduced)` | `data` を行階段形／簡約行階段形に変更し、ピボットの列番号を昇順の `vector<int>` で返す | $$O(n\min(n,c)s+nc+ns)$$ | $$O(n+\min(n,c)+s)$$ |
| `transpose(data,n,m)` | `n` 行 `m` 列の転置を、行ごとに詰めた `vector<Word>` で返す | $$O(nW(m)+mW(n))$$ | $$O(mW(n))$$ |
| `multiply(a,b,n,inner,m)` | `n` 行 `inner` 列と `inner` 行 `m` 列の積を、行ごとに詰めた `vector<Word>` で返す | 後述の $$O(P(n,k,m))$$ | $$O(nW(m)+mW(k)+W(m))$$ |

`bit` の `row` は、その列を含むワードまで読み取れる必要があります。`column` は非負です。`xor_row` の `first`・`stride` はビット番号ではなくワード番号です。`0 <= first <= stride` とし、読み書きする `to[first..stride)` と `from[first..stride)` は重ならないようにします。

`eliminate` の `rows`・`stride`・`columns` は非負の `int` で、表ではそれぞれ $$n,s,c$$ と書いています。`data.size() == size_t(rows) * stride` と $$c\le64s$$ が必要です。各行の先頭 `columns` 列だけをピボットに使いますが、行の XOR は末尾のワードまで行います。そのため、右辺や単位行列を後ろに付けた行列にも使えます。

`reduced = false` では、ピボットが下の行ほど右にあり、ピボットの下が全て 0 の行階段形を返します。`true` では、各ピボットの列で他の行も全て 0 の簡約行階段形を返します。ピボットの個数が階数です。係数部分が全て 0 の行は末尾に並びますが、そこに付けた右辺まで 0 になるとは限りません。ピボット列の範囲は `[0,columns)` です。

行の交換は作業中の参照先を交換し、最後に `data` の実際の行順へ反映します。返した後の `data` は追加の並べ替えなしに読み取れます。`rows == 0` または `columns == 0` では、変更せず空の列を返します。

通常の掃き出しと、最大 8 ピボットの XOR の組合せ表を使う掃き出しは、上記の同じ最悪時間の上界を満たします。組合せ表は最大 $$256s$$ ワードで、行の参照先・並べ替え用の配列・作業中の 1 行と、返すピボット列を合わせて $$O(n+\min(n,c)+s)$$ の追加空間です。入力 `data` 自体をコピーする領域は、この内部関数では使いません。

`transpose` の入力長は `n * W(m)`、返り値の長さは `m * W(n)` です。`multiply` の表では `inner` を $$k$$ とし、入力長はそれぞれ `n * W(k)`・`k * W(m)`、返り値の長さは `n * W(m)` です。これらの要素数は `size_t` と `vector<Word>::max_size()` の範囲に収めます。寸法は非負で、各入力行の未使用ビットは 0 にしてください。返り値でも未使用ビットは 0 です。入力配列は変更しません。

行列積の時間上界は

$$P(n,k,m)=nkW(m)+nmW(k)+kW(m)+nW(m)$$

です。左行の 1 に対応する右行を XOR する方法、右行列を転置して内積の 1 の個数の偶奇を求める方法、最大 8 行の XOR 組合せ表を使う方法のいずれも、この上界に含まれます。左行に 0 が少ない場合は、右行列の全行の XOR から、左行の 0 に対応する右行を XOR して結果を求めることもあります。この場合の作業用の行は $$W(m)$$ ワードです。

通常の組合せ表は最大 $$256W(m)$$ ワードです。$$W(m)\le64$$ の場合は、最大 8 組の表を使い、64 個の係数に対応する結果をまとめる場合があります。その表は最大 $$2048W(m)$$ ワード、1 MiB 以下で、空間の上界 $$O(W(m))$$ は変わりません。右行列を転置する場合の作業領域は $$mW(k)$$ ワードで、出力を含めた追加空間が表の上界になります。

`n == 0`・`k == 0`・`m == 0` の積も扱い、指定された形の零行列を返します。特に `k == 0` でも、出力の初期化に $$O(nW(m))$$ 時間・空間が必要です。空入力で配列を確保しない処理にも定数時間かかります。

作業配列と組合せ表は呼び出しごとに確保・解放します。共有する可変状態や、呼び出しをまたいで保持する前計算表はありません。

[通常版の行列](matrix.md) と [軽量版の行列](matrix_light.md) が共有するクラスです。利用するときは、それぞれの公開ヘッダーを include してください。

`Matrix<T,Arithmetic>` は、`Arithmetic` の行列積・要素の四則演算・専用累乗を使います。`Matrix<T>` の既定の演算は、include した行列ヘッダーに応じて通常版または軽量版になります。`LightMatrix<T>` は軽量版を明示する別名です。行列の保存形式と公開操作は共通です。

各操作の計算量は `Arithmetic` によって変わります。操作ごとの条件と時間は、指定した実装に対応する [通常版](matrix.md) または [軽量版](matrix_light.md) を参照してください。

要素の演算・コピー・破棄を定数時間として、$$n\times m$$ 行列の構築・コピー構築・加減算・定数倍は $$O(nm)$$ 時間・空間、要素の参照は $$O(1)$$ 時間です。$$n\times k$$ と $$k\times m$$ の積は両版とも $$O(nkm)$$ 時間で、追加空間は通常版で $$O(nk+km+nm)$$、軽量版で $$O(nm)$$ です。正方行列の逆行列・行列式・特性多項式は $$O(n^3)$$ 時間です。累乗の指数を $$k$$ とすると、通常版で専用処理を使える場合の $$O(n^3+n^2\log k)$$ と、繰り返し二乗による $$O(n^3\log k)$$ を区別します。0 乗は $$O(n^2)$$ 時間です。正方行列の追加空間は $$O(n^2)$$、行列積以外の長方行列の各操作の追加空間は、解空間の出力を除き $$O(nm)$$ です。

行列自身の保持空間は、内部配列の確保容量を $$C$$ として $$O(C)$$ です。小さい行列をコピー代入した後も以前の容量を保持する場合があります。コピー代入先の元の要素数を $$L$$ とすると、元の要素の破棄を含めたコピー代入の時間は $$O(nm+L)$$ です。

容量と単位費用を持つ有向グラフで、指定した始点から終点へ流す量と、その最小費用を求めます。`flow(s,t,limit)` は `limit` 以下で可能な最大の追加流量と、その最小費用を返します。辺に下限を付ける場合や、頂点ごとに出る量と入る量の差を指定する場合は [MinCostBFlow](min_cost_b_flow.md) を使います。

```cpp
#include "lib/graph/min_cost_flow.hpp"
#include <cassert>

int main() {
	MinCostFlow<> graph(3);
	graph.add_edge(0, 1, 5, -2);
	graph.add_edge(1, 2, 3, 7);
	auto [flow, cost] = graph.flow(0, 2, 2);
	assert(flow == 2 && cost == 10);
	auto [next, extra_cost] = graph.flow(0, 2, 2);
	assert(next == 1 && extra_cost == 5);
	assert(graph.get_edge(0).flow == 3);

	graph.reset_flow();
	assert(graph.get_edge(0).flow == 0);
}
```

容量 `cap` の辺に流量 `f` を流すと、元の向きにはさらに `cap - f`、逆向きには取り消すために `f` だけ流せます。この追加・取り消しに使える量を辺の容量として持つグラフを、残余グラフと呼びます。元の辺の単位費用が `c` なら、逆向きの辺の単位費用は `-c` です。

ポテンシャルは、各頂点に付ける費用の補正値 `p[v]` です。辺 `u -> v` の単位費用 `c` を `c + p[u] - p[v]` に置き換えた値を、補正後の費用と呼びます。残余容量が正の全ての辺でこの値が非負になるように選ぶと、負の費用の辺があっても Dijkstra 法を使えます。

表の $$N$$ は頂点数、$$M$$ は辺数、$$U\geq2$$ は容量と各回の流量上限の最大値の上界、$$A$$ は `slope` で経路に流量を追加する回数です。固定幅整数の演算を定数時間として、時間と返り値を含む追加空間を書きます。「初期化」は、残余容量が正の辺の費用が全て非負なら $$O(N+M)$$、一般には $$O(NM)$$ 時間です。初期化は、補正値が未準備の場合に行います。

| 操作・型 | 内容・返り値 | 時間計算量 | 追加空間 |
| --- | --- | --- | --- |
| `MinCostFlow<Cap,Cost,Total>(n = 0)` | `n` 頂点で構築。既定は `std::int64_t`・`std::int64_t`・`__int128_t` | $$O(1)$$ | $$O(1)$$ |
| `size()` / `edge_count()` | 頂点数／辺数を `int` で返す | $$O(1)$$ | $$O(1)$$ |
| `reserve(m)` | 元の辺 `m` 本分の領域を確保 | 再確保時 $$O(M)$$、確保済みなら $$O(1)$$ | 再確保時 $$O(m)$$、確保済みなら $$O(1)$$ |
| `add_edge(from,to,cap,cost)` | 容量と単位費用を指定して有向辺を追加し、0 始まりの辺番号を `int` で返す | 償却 $$O(1)$$ | 通常 $$O(1)$$、再確保時 $$O(M)$$ |
| `flow(s,t,limit = Capの最大値)` | 最大追加流量と今回増えた費用を `pair<Cap,Total>` で返す | 初期化＋ $$O(M(N+M\log N)\log U)$$ | $$O(N+M)$$ |
| `slope(s,t,limit = Capの最大値)` | 今回の追加流量と費用の折れ線を `vector<pair<Cap,Total>>` で返す。最初は `(0,0)`、傾きが同じ区間は統合 | 初期化＋ $$O(A(N+M))$$ | $$O(N+M+A)$$ |
| `get_edge(i)` | 辺番号 `i` の容量・単位費用と現在の流量を `Edge` で返す | $$O(1)$$ | $$O(1)$$ |
| `edges()` | 全辺の情報を追加順の `vector<Edge>` で返す | $$O(M)$$ | $$O(M)$$ |
| `reset_flow()` | 全ての流量を 0 に戻す。頂点と辺は残す | $$O(M)$$ | $$O(1)$$ |
| `potentials()` | 現在の残余グラフの補正値を `const vector<Cost>&` で返す | 準備済みなら $$O(1)$$、必要なら初期化 | 準備済みなら $$O(1)$$、初期化時 $$O(N)$$ |
| `Edge` | `int from,to`、`Cap cap,flow`、`Cost cost` をこの順に持つ | —（型） | —（型） |
| `capacity_type` / `cost_type` / `total_type` | それぞれ `Cap`・`Cost`・`Total` の別名 | —（型） | —（型） |

頂点番号は `[0,N)`、辺番号は `[0,M)` です。自己辺・多重辺・負の費用に対応します。**各呼び出し前の残余グラフ全体に負閉路がないこと**が必要です。負の辺がある場合も、補正値を求めてから処理します。

`Cap` は 64 bit 以下の標準整数型で `bool` を除き、容量・流量上限は非負です。`Cost` は 64 bit 以下の標準の符号付き整数型、`Total` は符号付き整数型です。`cost` に `Cost` の最小値は指定できません。補正値・最短距離・補正後の費用とそれらの計算途中は `Cost` に、費用合計と積は `Total` に収めてください。有限の最短距離は `Cost` の最大値未満にします。この最大値は到達できないことを表すために使います。既定の合計値は [FastOutput](fast_io.md) で出力できます。

`s`・`t` は相異なる有効な頂点にします。頂点数は非負、元の辺数は `INT_MAX/2` 以下です。`flow` と `slope` は現在の残余グラフから続け、返り値の流量・費用は今回の追加分です。容量が足りなければ流せた最大量を返すため、全て流せたかは `flow == limit` で確認します。始点・終点を変えることもできます。辺の追加後も続けられますが、負閉路が生じないことを確認してください。

`slope` は最短の経路へ順に流量を追加し、費用の変わり方を全て求めます。`potentials()` の参照は次の変更操作まで有効です。辺追加の「償却」は、連続して追加したときの 1 回あたりの平均です。

表の `flow` の式は $$M\geq1$$ の場合です。辺がない場合や流量上限が 0 の場合は初期化に加えて $$O(N+M)$$ 時間、`slope` で追加が 0 回の場合も初期化に加えて $$O(N+M)$$ 時間です。辺追加後の最初の流量計算には、隣接配列の構築 $$O(N+M)$$ も含みます。保持空間と作業空間は $$O(N+M)$$、`slope` の返り値は $$O(A)$$ 空間で、追加が 0 回なら定数空間です。領域を余分に予約した場合や `reset_flow()` 後も、確保済みの配列領域は残ります。共有する前計算はありません。

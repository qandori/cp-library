# Dynamic Segtree の比較

```sh
g++ -std=c++23 -O2 -DNDEBUG -I . test/benchmark/dynamic_segtree.cpp -o /tmp/dynamic-segtree-bench
/tmp/dynamic-segtree-bench 2 0 100000 200000 1
```

引数は実装、座標分布、点数、更新・問い合わせの各回数、予約の有無です。

実装は 0 が各階層にノードを作る通常版、1 が1座標1ノードで経路を圧縮しない版、2 が本ライブラリです。座標分布は 0 がランダム、1 が狭い範囲に集中、2 が昇順、3 が降順です。座標範囲は $$[0,2^{62})$$ です。予約ありでは通常版が $$4n$$ ノード、他2方式が $$n$$ ノードを初期予約します。

2026-10-15、macOS arm64。GCC 15.2 と Apple Clang で4分布・3実装を各3回測定し、各実装のチェックサムが一致することを確認しました。以下は GCC、10万点・20万更新・20万問い合わせ、予約ありの中央値です。ノード領域は予約容量を含み、入力・クエリ配列は含みません。

| 分布 | 実装 | 構築 ms | 更新 ms | 問い合わせ ms | ノード領域 MB |
| --- | --- | ---: | ---: | ---: | ---: |
| ランダム | 通常版 | 86.61 | 133.71 | 60.93 | 102.40 |
| ランダム | 1座標1ノード | 12.15 | 24.93 | 39.36 | 3.20 |
| ランダム | 本ライブラリ | 12.82 | 28.24 | 41.60 | 3.20 |
| 集中 | 通常版 | 167.77 | 120.06 | 81.28 | 6.40 |
| 集中 | 1座標1ノード | 59.95 | 163.24 | 90.45 | 3.20 |
| 集中 | 本ライブラリ | 14.86 | 31.37 | 53.76 | 3.20 |

比較の結果、1座標1ノードの方式に経路圧縮を加え、分岐位置を子ノード番号の上位 bit に格納しました。再帰更新・反復更新、集約時の条件分岐あり・なしも比較し、反復更新と単位元ノードを使う版を採用しています。

座標と値が64 bit の場合、本実装のノードは32バイトで、分岐位置のための追加領域はありません。

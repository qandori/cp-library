符号付きの任意精度整数です。四則演算・剰余・比較と、10 進文字列との相互変換を扱います。

```cpp
#include "lib/math/bigint.hpp"
#include <cassert>

BigInt a("123456789012345678901234567890");
BigInt b = -7;
auto [q, r] = divmod(a, b);
assert(q.to_string() == "-17636684144620811271604938270");
assert(r == 0);
assert(q * b + r == a);

BigInt x = -17;
assert(x / 5 == -3);
assert(x % 5 == -2);
assert(abs(x) == 17);
assert(BigInt("+0000").sign() == 0);
assert((a + 10).to_string() == "123456789012345678901234567900");
```

| 操作 | 内容・返り値 |
| --- | --- |
| `BigInt()` | `0` を作る |
| `BigInt(value)` | 128 bit 以下の組み込み整数から正確に作る。暗黙変換可 |
| `BigInt(text)` | `std::string_view` の 10 進整数から作る。明示的な変換 |
| `a.to_string()` | 符号付き 10 進表記の `std::string` を返す |
| `a.sign()` | 負・零・正について、それぞれ `-1`・`0`・`1` を `int` で返す |
| `bool(a)` | `a != 0` を返す。`bool` への変換は明示的 |
| `+a`, `-a`, `abs(a)` | 符号を保った値・符号反転した値・絶対値を `BigInt` で返す |
| `a + b`, `a - b`, `a * b` | 和・差・積を `BigInt` で返す |
| `a / b`, `a % b` | 商・余りを `BigInt` で返す |
| `divmod(a,b)` | 商と余りの `std::pair<BigInt,BigInt>` を返す |
| `a += b`, `a -= b`, `a *= b`, `a /= b`, `a %= b` | 左辺を更新し、`BigInt&` を返す |
| `++a`, `--a` | 1 増加・減少し、更新後の `BigInt&` を返す |
| `a++`, `a--` | 1 増加・減少し、更新前の `BigInt` を返す |
| `a == b`, `a != b`, `a < b`, `a <= b`, `a > b`, `a >= b` | 数値を比較し、`bool` を返す |
| `a <=> b` | `std::strong_ordering` を返す |
| `out << a`, `in >> a` | 10 進表記で入出力し、ストリームの参照を返す |

整数からの構築は、符号付き・符号なしの両方に対応します。`__int128_t`・`__uint128_t` の最小値・最大値も表せます。`a + 1`・`1 + a` のように、組み込み整数と混在させられます。

文字列の形式は、省略可能な先頭の `+` または `-` と、それに続く 1 桁以上の `0`～`9` です。先頭の零は許容し、`-0`・`+000` も `0` として扱います。空文字列、符号だけ、空白、10 進数字以外を含む文字列では `std::invalid_argument` を送出します。`to_string()` は正の値に `+` を付けず、不要な先頭の零も出力しません。

商は零に向かって切り捨てます。余りは零または被除数と同じ符号で、`a == (a / b) * b + a % b`、`abs(a % b) < abs(b)` を満たします。零除算では `std::domain_error` を送出します。商と余りの両方が必要な場合は、除算を共有する `divmod(a,b)` を使ってください。

複合代入には `a += a`・`a *= a`・`a /= a` なども指定できます。コピーは独立した値を作り、ムーブ後の元の値は `0` になります。自己ムーブ代入は値を保ちます。

ストリーム入力は空白で区切った文字列を 1 個読み、その文字列全体を 10 進整数として解釈します。不正な入力では `failbit` を立て、代入先の値を保ちます。ストリームの `std::hex`・`std::oct` を指定しても、16 進・8 進では読み込みません。

桁数は固定されませんが、[NTT（法を使った畳み込み用の変換）](ntt.md)を使う内部乗算では、繰り上げ前の係数列の長さが $$2^{24}$$ 以下である必要があります。この上限を超える乗算は `std::length_error` を送出します。除算も内部で乗算を行うため、同じ上限が適用されます。確保できるメモリにも依存します。

参考: [Nyaan's Library の多倍長整数](https://github.com/NyaanNyaan/library/blob/master/math/bigint/bigint.hpp)。

内部では 10 進 9 桁ずつをまとめて 1 桁として保存します。この桁数を $$n,m$$、$$n\ge m$$、長さ $$k$$ の乗算時間を $$M(k)$$ とします。10 進文字列との変換は文字数に対して線形、加減算・比較は最悪 $$O(n)$$ 時間です。小さい乗算は $$O(nm)$$、NTT を使う乗算は $$O((n+m)\log(n+m))$$ 時間です。被除数が除数以上の場合、小さい除算は商の桁数を $$q$$ として $$O(qm)$$、逆数を使う除算は $$O(\displaystyle\frac{n}{m}M(m))$$ 時間です。商の桁数は $$q\le n-m+1$$ です。被除数が除数未満なら、除算は余りのコピーを含め $$O(n)$$ 時間です。大きな乗算・除算の追加空間は $$O(n+m)$$ です。符号と零の判定は $$O(1)$$、コピー構築・単項演算・絶対値・1 の増減は $$O(n)$$ 時間です。既定構築と固定幅整数からの構築は $$O(1)$$ 時間です。

値の保持領域は、確保済みの桁数を $$C$$ として $$O(C)$$ です。桁数が減っても領域が縮まるとは限らず、例えば `x -= x` で 0 にしても以前の領域を保持する場合があります。コピー構築の空間は現在の桁数 $$n$$ に対して $$O(n)$$、コピー代入の時間は代入前の桁数を $$q$$ として $$O(n+q)$$ です。

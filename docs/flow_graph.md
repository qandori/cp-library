---
title: "フローの残余グラフ"
documentation_of: //components/flow_graph.hpp
library_category: components/graph
---

`flow_detail::Graph<Cap>` は最大流・最小費用流で使う残余グラフです。残余グラフは、各辺にまだ追加で流せる量を持ち、流した分を取り消すための逆向きの辺も持つグラフです。元の向きの辺を正辺、取り消す向きの辺を逆辺と呼び、両者を連続して保存します。

| 操作・メンバ | 内容・返り値 | 計算量 |
| --- | --- | --- |
| `Graph(n=0)` | 頂点数を指定して構築 | $$O(1)$$ |
| `reserve(m)` | 元の辺 `m` 本分を確保 | $$O(M)$$ |
| `add_edge(from,to,cap)` | 正辺と容量 0 の逆辺を追加し、元の辺番号を返す | 償却 $$O(1)$$ |
| `build()` | 隣接する残余辺の添字を連続配列に構築。変更がなければ何もしない | 初回: $$O(N+M)$$、構築済み: $$O(1)$$ |
| `reset_flow()` | 逆辺の容量を正辺へ戻し、流量を 0 にする | $$O(M)$$ |
| `n` / `built` | 頂点数／隣接配列が有効か | $$O(1)$$ |
| `arcs` / `Arc` | `to`・`cap` を持つ残余辺の配列／その型。逆辺は添字の下位 bit を反転して得る | $$O(1)$$ |
| `start` / `order` | 頂点ごとの隣接区間／その区間に並ぶ残余辺の添字 | $$O(1)$$ |

頂点は 0 始まり、容量は非負、元の辺数は `INT_MAX/2` 以下にします。容量型の条件は公開フローライブラリと同じです。

$$N$$ 頂点・$$M$$ 辺として、構築は $$O(1)$$、追加は償却 $$O(1)$$、初回・辺追加後の `build` は $$O(N+M)$$、その他の `build` は $$O(1)$$、`reset_flow`・領域を増やす `reserve` は $$O(M)$$、空間は $$O(N+M)$$ です。
